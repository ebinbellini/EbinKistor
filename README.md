## EbinKistor

Easy to use, vanilla friendly, fully server side trading and locking fabric mod for Minecraft 1.21.5

This mod also includes a simple economy with a currency called blocksdaler.

### Locking
Use a stick and right click on a chest. It is now locked! Only you can open it. This protects against:

- Explosions, eg. TNT, end crystals
- Wither break mechanics
- Placing chests next to it
- Breaking
- Hoppers

Unlock using a stick again. Only you can unlock your chest.

### Selling items
1. Create a chest and put in the item you want to sell. You cannot put multiple different items in the chest.
2. Lock the chest using a stick.
3. Place a sign with "KÖP" as the first line and the price as the last line. The lines in-between can say anything you want, for example "exquisite marble".
4. Hold redstone dust and right click on the sign and then the chest.
5. Any player can now right click the sign to buy.

### Buying items
1. Create a chest and put in at least one instance of the item you want to buy. Only this item can be sold at the store.
2. Lock the chest using a stick.
3. Place a sign with "SÄLJ" as the first line and the price as the last line. The lines in-between can say anything you want, for example "high quality copper ingots".
4. Hold redstone dust and right click on the sign and then the chest.
5. Any player can now right click the sign while holding the item to sell.

Enjoy! If you have any problems, create an issue request on the GitHub page.
